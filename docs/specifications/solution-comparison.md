# Спецификация: сравнение решений

- **Статус:** Draft
- **ТЗ:** 2.7 · **Roadmap:** LRN-036, TEC-049

## Критерии

Корректность, вычислительная сложность, пространственная сложность,
устойчивость, точность, читаемость, расширяемость, применимость в условиях
задачи. Набор и веса задаёт дисциплина (по умолчанию) и манифест Issue
(переопределение): у численных методов вес у устойчивости и точности, у
веб-интерфейсов — у читаемости и расширяемости.

## Источники оценок

| Критерий | Чем измеряется |
|---|---|
| корректность | тесты в песочнице (INF-016) |
| сложность | заявленная учеником оценка + анализ сложности, когда появится (INF-021) |
| устойчивость, точность | тестовые наборы с плохо обусловленными входами, сравнение с эталоном (INF-019) |
| читаемость, расширяемость | статический анализ (INF-022) и ревью коммитов; модель — только как предложение с `reliability = low` |
| применимость | критерии `method_choice` задачи |

## Пример ТЗ

Поиск корня: бисекция, Ньютон, секущие — три решения одной Issue (сценарии
TEC-030). Таблица сравнения по критериям; обоснование выбора — критерий
применимости (наличие производной, гарантия сходимости, число итераций).
Оценивается обоснованность выбора, а не только ответ.
