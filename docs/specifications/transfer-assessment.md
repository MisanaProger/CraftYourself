# Спецификация: проверка переноса знаний (Transfer v2)

- **Статус:** Draft
- **ТЗ:** 2.6 · **Roadmap:** LRN-034, TEC-052, RND-010

## Сейчас

`est_discipline::transfer`: завершённая практика или Issue с Practice ≥ 60
даёт Transfer навыкам, у которых раньше было свидетельство в другом
контексте (`lesson`, `problem`, `project:<id>`). Смена контекста
достаточна — воспроизведение решённого примера в новом проекте тоже
засчитывается.

## v2

Transfer-свидетельство (`new_context_application`) требует задачи переноса —
задачи, помеченной в манифесте или сгенерированной (TEC-032) с полями:

- `transfer_of` — навык и исходный объект;
- `changed` — что изменено (предметная область, ограничения, представление
  данных, дисциплина);
- `method_choice` — критерии, по которым проверяется выбор метода
  (например, для метода Ньютона: проверка условий сходимости, обоснование
  начального приближения, запасной метод при нулевой производной).

Балл = Practice задачи × доля выполненных критериев `method_choice`.
Задача, решённая с ответами L3+, даёт `hinted_solution`, а не Transfer.
Сравнение первого и повторного применения — пара записей с одним
`transfer_of`; показывается в объяснении оценки.

Совместимость: свидетельства v1 сохраняются с `rule_version` v1 и
продолжают учитываться, пока у навыка нет v2.
