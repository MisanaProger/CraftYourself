# Спецификация: адаптивное обучение

- **Статус:** Draft
- **ТЗ:** 2.5, 2.11 · **Roadmap:** LRN-022 (LRN-023 … LRN-026), LRN-033, TEC-041 (TEC-042, TEC-043, TEC-050), PRD-033, PRD-042

## Принципы

1. Решения принимает код (`est-adaptive`, `est-ai-policy`); модель может
   сформулировать объяснение, но не меняет ранжирование, сложность или
   бюджет (AGENTS.md, правило 1).
2. Адаптация не трогает engagement: каждая Issue начинается с L0,
   эскалация — одна ступень с согласием (правило 2).
3. Используется история, а не последний результат; все изменения
   траектории записываются с причиной (TEC-043).

## Adaptive Difficulty (LRN-023)

Целевая сложность (`beginner | intermediate | advanced`, как
`est_domain::Difficulty`) для дисциплины — по тренду баллов её навыков за
окно последних 5 свидетельств High/Medium:

- среднее ≥ 80 и доля `independent_solution` ≥ 60 % → на ступень выше;
- среднее < 50 или доля `hinted_solution` с L3+ ≥ 50 % → на ступень ниже;
- иначе без изменений.

Один результат не сдвигает больше чем на ступень; изменение — запись в
журнале траектории.

## Hint Budget (LRN-024, TEC-050)

- Счётчики подсказок по Issue и этапу жизненного цикла (Investigation,
  Solution, Testing) из событий engagement — без разбора текста.
- Бюджет Issue (по умолчанию 5 подсказок L1) не запрещает помощь: при
  исчерпании ментор предлагает сначала вернуться к критериям и тестам, а в
  свидетельстве тип становится `hinted_solution`.
- Бюджет живёт в `est-ai-policy` и никогда не повышает уровень.

## Learning Path Generator (LRN-025)

Детерминированное ранжирование кандидатов (Issue, задачи, уроки,
контрольные) по сумме вкладов, каждый с причиной:

| Вклад | Источник |
|---|---|
| закрывает незакрытую предпосылку цели | граф, TEC-024 |
| узкое место (блокирует несколько целей) | LRN-026 |
| навык в очереди перепроверки | retention, LRN-021 |
| исправляет заблуждение | LRN-031 |
| соответствует целевой сложности | LRN-023 |
| соответствует цели ученика | PRD-036 |

Модель (как сейчас в рекомендациях) получает уже ранжированный список и
пишет объяснение; ссылки и порядок — только из списка.

## Learning Bottleneck Detection (LRN-026)

Навык — узкое место, если он входит в `critical_gaps` для ≥ 2 целей
(навыков, которые ученик выбрал или которые требуются его Issue).

## <a id="confidence"></a>Confidence Tracking и Calibration (LRN-033)

- Перед контрольной задачей ученик указывает уверенность 0–100 (по
  шагам 10); это данные, не свидетельство.
- Калибровка за последние 10 контрольных: средняя разность
  «уверенность − результат» (знак: завышение/занижение) и доля совпадений
  в пределах 20 пунктов; тренд по окнам. Выбор метрики — эксперимент
  RND-011.

## Журнал траектории (TEC-043)

`trajectory_changes` (append-only): дата, что изменилось (сложность,
порядок пути, бюджет), было/стало, причина (ссылки на записи
свидетельств, пробелы, сигналы), версия правил. Показывается ученику
(PRD-033), входит в экспорт.
